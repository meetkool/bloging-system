# Automatic Blog Post Generation! 🚀

This post was created by simply adding an MDX file to the `/posts` folder. Here's how it works:

## The Magic Behind the Scenes ✨

When you add a new `.mdx` file to the `/posts` folder:

1. **Contentlayer watches** the posts directory
2. **Automatically processes** the frontmatter
3. **Generates type-safe data** from your content
4. **Updates the blog list** on your homepage
5. **Creates the individual post page** at `/blog/[filename]`

## Required Frontmatter Fields

Every MDX file needs this structure at the top:

```yaml
---
title: Your Post Title
date: 2024-09-25
excerpt: Brief description of your post
tags: [tag1, tag2, tag3]
cover: /path-to-your-image.jpg
---
```

## That's It! 🎯

No manual configuration needed. Just:
- Create `.mdx` file
- Add proper frontmatter
- Write your content
- Run `npx contentlayer build` (or restart dev server)

Your post appears automatically in the blog list and gets its own URL!

## Example Workflow

1. **Create**: `posts/my-awesome-post.mdx`
2. **Access**: `http://localhost:3000/blog/my-awesome-post`
3. **Appears**: On homepage blog list automatically

This is the power of **static site generation** with **type-safe content management**! 🔥
